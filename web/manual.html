🌍① 如何打开世界

无需安装、无需联网，双击一个文件即可。

  1. 打开项目里的 web 文件夹。
  2. 双击 web\world.html，浏览器（推荐 Chrome / Edge）会直接打开 3D 微观世界。
  3. 进入后会自动放飞一只果蝇 🪰，右侧出现"上帝控制台"，可以开始玩啦。
📎 依赖文件（请保持 web\ 目录结构不变，含 vendor\ 子目录）：
vendor\three.min.js（3D 引擎）、snn_data.js（训练好的 SNN 权重与拓扑）、snn_runtime.js（浏览器端脉冲推理引擎）、scene_fx.js（精修模型与四场景特效）、brain_panel.js（🧠 果蝇大脑面板）。
缺少任何一个都会开天窗（只剩面板或空背景），请勿单独移动 world.html 或打散目录结构。

🔬④ 实验玩法（这里是验证台，不只是看风景）

每一个按钮都对应实验报告里的一个实验变量——玩 = 做实验。

🧍➡️🚁 换身体实验（对应实验矩阵 D：果蝇身体 vs 无人机身体）

选中个体后点「果蝇身体 / 无人机身体」，同一个大脑，新的身体：

  • 🪰 果蝇身体：轻盈、爆发快，加速度和极速都大；
  • 🚁 无人机身体：有惯性、加速度受限，反应"肉"一点。

于是你可以直观看到：同一个逃逸决策，装在不同动力学的身体上，"怎么躲"的轨迹和手感会不同。诚实提醒（REPORT 第 3.4 节实测）：在突发威胁的短促窗口里，两种身体的成功率几乎持平（果蝇 0.698 vs 无人机 0.694，物理积分口径，见 REPORT 3.4）——差距不在神经决策，而在执行动力学；要真正"躲得开"，还需要更早的预警 + 更强的机动动力。这正是"仿生脑 + 无人机体"要回答的问题。

🎯 威胁投放（与实验矩阵 C 相关：突袭速度）

红色扑击球 / 青蛙弹舌 / 蜻蜓俯冲的突袭速度在约 3–9 m/s 内随机（本世界参数设定：球 3.5–9.0、蛙 5.0–8.0、蜓 3.0–8.0 m/s；没有低速档）。脱靶量范围由「精准 ↔ 宽松」滑杆控制（v5 新增，默认精准 0–1.2cm，即招招贴身、下下计分；拖到宽松则恢复 0–4.5cm 大范围，出现更多擦边虚惊）——有的真的会撞上（计分回合），有的只是虚惊（若果蝇对它起跳过，记 1 次"虚警"）。连点「自动威胁 ×10」可以高强度压测。严格的低/中/高速对照（实验矩阵 C）在 REPORT 第 3.3 节（由评估脚本生成）。

📊 一键跑 100 次统计（与训练端指标同算法）

点「一键跑 100 次统计」，程序在后台生成 100 个随机威胁场景并结算，输出四项：

【场景名】100 场景：触发 x% 　成功 y% 　方向 z° 　潜伏 w ms

  • 触发准确率：判断"有没有威胁、该不该跳"答对的比例（以 GF 是否放电为判据）；
  • 避障成功率：构成触发条件的威胁（正在接近、碰撞时间 < 50ms、距离 < 25cm，与脱靶量无关）中「GF 放电且方向误差 < 30°」的占比（与训练脚本 train_snn.py 的评估算法一致）；
  • 方向误差：逃逸方向与"背离威胁"的平均夹角（对全部有效威胁样本取平均，含未放电回合；与 HUD 的方向误差口径不同）；
  • GF 潜伏期：上述威胁里 GF 真放电的回合，从决策到首次放电的平均毫秒数（没放电的回合不计入）。
💡 统计用的是当前场景的视觉增益：切到「黑夜」再跑 100 次，就能看到弱视觉下的表现下滑（B 组的弱视觉条件可一键体验）。注意：「大风」的环境风干扰机制在这个简化统计里未建模（世界里的大风只吹动机体、不进统计），大风组的严格数据以 REPORT 第 3.2 节为准。

✅ 数值验收看这里（B 类验收指引）

✅ 语义 / 观感 / 科学验收看这里（A / C / D 类）

A 类 · 语义（操作 → 预期现象，人眼确认）：

  • ① 不投威胁、静置 1 分钟 → 只见自动漫游，不应出现「⚡ 逃逸！」大字，HUD"虚警"计数应为 0；

❓⑤ 常见问题

Q1：为什么"纯视觉模式"下风压不生效？是 bug 吗？
A：不是 bug，是对照实验故意关闭的。"纯视觉"是模态对照组：为了量化"只靠视觉"能做到多少，会把风觉输入通道的脉冲整体关掉，所以风压读数不参与决策。反过来，"纯风觉"（wind_only）是把视觉通道的脉冲整体关掉。3D 世界（world.html）默认是融合模式，模态对照在训练 / 评估端进行；想在浏览器里粗看模态差异，可打开同目录的旧沙盒 index.html（有纯视觉 / 纯风觉下拉）。
Q2：成功率是怎么算的？
A：注意这里有三种口径，别混用：① 屏幕累计的"成功率"（左上 HUD）＝计分回合（脱靶量 < 威胁半径 + 0.55cm + 1.2cm 余量，即"真的可能撞上你"）中「起跳逃逸且最终没被撞」的占比，不检查方向角；② 「一键 100 次」和实验报告的"避障成功率"＝"构成触发条件的威胁"（正在接近、碰撞时间 < 50ms、距离 < 25cm，与脱靶量无关）中「GF 放电且逃逸方向误差 < 30°」的占比；③ 实验报告 D 组"换体实验"用的是物理积分口径（把双方运动逐毫秒真结算，安全 = 最近距离 > 半径和，见 REPORT 3.4），数值与②不同、不可混用。虚警单列：够不上计分线（脱靶量 ≥ 威胁半径 + 0.55cm + 1.2cm 余量）的威胁却起跳了，单独计进"虚警"计数，不进成功率。（边界：够不上计分线的威胁即使真的撞上你，本世界也不记"被撞"、不会"结束这一世"；但若你对它起跳过，照常计 1 次"虚警"。）
Q3：果蝇死了会怎样？要不要重新训练？
A：被命中只是"这一世结束了"，会自动复活 = 出厂重置（位置、速度复位）；本能权重仍在（SNN 是固定拓扑 + 训练好的权重），完全不需要重新训练。（边界：够不上计分线的威胁撞上你时不会"结束这一世"，见 Q2。）
Q4：能拖动鼠标旋转视角吗？
A：当前版本视角自动跟随选中个体（第三人称），只有滚轮缩放；拖动旋转暂未实现（按住个体拖动换位置是另一个功能，已支持）。
Q5（v5 新增）：🧠 大脑面板怎么读？那些点亮来亮去的是什么？
A：面板画的是真实连接组（1871 神经元 / 45524 边）在一次决策窗（12 毫秒）里的逐毫秒放电重放。点阵：每个点=一个神经元，亮=这毫秒放电——左上 LPLC2 视觉 210（按偏好方位排序，威胁方位对应列先亮）、左下 JO 风觉 325、中间 中间神经元 1165（抽样 128 显示）、中右 GF ×2、右侧 下游 169；流带上的绿色粒子=脉冲在群间传导（数字是真实突触边数）。下方曲线：横轴 12 个毫秒步，纵轴 GF 膜电位，两条线=两个 GF，金色虚线是 Vth 阈值（1.00）；曲线越线 = GF 放电 = ⚡逃逸触发（越线处图上直接标 ⚡），全程压在虚线下=静息。面板只是"旁路抄表"，不改变 SNN 任何数值（关掉后计算路径逐位不变）。
Q6（v5 新增）：「脱靶量范围」滑杆（精准 ↔ 宽松）是干嘛的？
A：它控制新投放威胁的瞄准脱靶量范围（发射时你站着不动、威胁与你的最近距离）。精准（默认）=0–1.2cm：招招贴身，几乎每个都是"计分回合"，适合压测逃逸；拖到宽松=0–4.5cm：更多"擦边而过"的虚惊（若果蝇对虚惊起跳会计"虚警"）。它只影响之后新投的威胁，不影响已在飞的。滑杆改的是攻击方式，不改大脑数值——SNN、评估口径均不变。
Q7（v5 新增）：以前说"场景只是换色"，现在呢？
A：v5 起四场景是实质差异：白日草原=草浪 + 云影掠地 + 花粉；黑夜=月亮 + 星空 + 140 只萤火虫闪烁漫游（冷色月光）；暴风=700 段斜雨雨幕 + 高速风线 + 草狂摆 + 机体被风吹偏；大风=520 个气流粒子沿流场流动（把"风"变成看得见的流线）。光照也分色温（日暖月冷）并带阴影贴图。注意场景仍按实验矩阵 B 的口径影响视觉增益（晴 1.0 / 黑夜 0.3 / 暴风 0.85），玩统计时切场景=换实验条件。
