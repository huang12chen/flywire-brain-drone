# 《果蝇·微观世界》v1 设计文档（最终裁剪版）

> ⚠️ 本文为 2026-09-22 历史设计稿，**非实现说明**：含未实现的功能设想（如暂停/慢动作、个体数上限等）。实际实现以 `web\使用手册.html` 与 `web\world.html` 为准。

日期：2026-09-22　状态：已与用户对齐
定位：**科学成果为主，3D 开放世界为验证台 + 演示橱窗**。目标应用领域：无人机仿生避障/反干扰（仿生控制）。

## 0. 核心科学主张（实验要证明/证伪的东西）

1. 以**真实 FlyWire 连接组拓扑为约束**的 SNN（1871 节点 / 45524 边，仅调权重不改连线）能完成"视-风融合威胁逃逸控制"。
2. **融合 > 单模态**：方向精度与避障成功率上融合显著优于纯视觉；纯风觉为弱线索（近距离/补充）。
3. **跨载体有效性**：同一控制器换装"果蝇身体"与"无人机身体"（不同质量/推力/惯性）均能有效避险。
4. **环境鲁棒性矩阵**：晴天 / 大风（风觉持续激励）/ 黑夜（视觉衰减）/ 高速突袭 四场景下的性能退化可量化。

## 3. 3D 试验场（P0）设计

- 视觉：原神式卡通渲染。渐变天空穹顶 + 云、远山、雾、阳光；InstancedMesh 草叶（≈6000）摇摆、野花、蘑菇、低多边形树、池塘水面。
- 场景 = 实验变量：🌿 草原（默认）/ 🌪️ 大风（草弯、机体受扰、风觉持续放电）/ 🌑 黑夜（视觉输入按亮度衰减、萤火虫）/ 🪷 池塘·近水低空。
- 载体（换体实验）：果蝇身体（1.5 m/s 起跳、轻）/ 四旋翼机身（推力-惯性模型、加速度受限）——同一 SNN 输出。
- 威胁物（统一抽象为"高速逼近物体"，生成真实 looming + 风压线索）：红色扑击球（基线）、弹舌青蛙、俯冲蜻蜓。
- 上帝控制台：放置/删除个体（≤8）、投放威胁、切场景天气、暂停/慢动作、换身体、**一键跑 100 次统计**（口径与 train_snn.py 评估完全一致）。
- 指标 HUD：触发准确率 / 避障成功率 / 方向误差 / GF 潜伏期，实时 + 累计。
- 记分修正：仅统计"构成碰撞威胁"的回合（碰撞时间 < 阈值者），虚警单独计数。

## 4. 控制权开关（最小实现，安全相关）

- 二态开关：🛫 手动（SNN 仅观察记录，绝无输出）/ 🤖 仿生（SNN 全权）。
- 飞手任何输入立即接管并压制 SNN 输出（0 延迟）。
- 失效安全：任何异常时 SNN 输出归零 = 手动态。
- 真机级三模式仲裁（辅助模式等）列入展望，不属 v1。

## 5. 实验矩阵（REPORT.md 的骨架）

| 组别 | 输入 | 场景 | 指标 |
|---|---|---|---|
| A 对照 | 融合 / 纯视觉 / 纯风觉 | 晴天 | 触发准确率、成功率、方向误差、潜伏期 |
| B 环境 | 融合为主 | 大风 / 黑夜 | 同上，量化退化 |
| C 突袭速度 | 融合 | 低/中/高速 | 起跳距离、成功率 |

每格 ≥5 次重复（不同种子），报告均值 ± 标准差。

## 6. 技术要点

- 复用：snn_runtime.js（推理）、snn_trained.json（v3 权重：触发 79.9%、成功 90.3%、方向 10.7°、潜伏 7.65ms）。
- 物理：自研轻量积分（球体/刚体级），单位 cm 与 cm/ms，与训练端公式一致（looming = −2sṙ/(r²+s²)×1000；风压 u = s²|v|/r²）。
- 伪随机固定种子；evaluate.js 输出 JSON 供报告引用。
- 验收沿用 A 语义（一票否决）/ B 数字 / C 画面 / D 科学性 四类清单。

## 7. 风险

- 3D 性能：草叶与多机体实例化，目标 60fps；不达标先降草叶密度。
- 训练数据为合成线索（非实测），报告必须声明；无人机应用需经 PX4 SITL → 真机链路验证（展望）。
