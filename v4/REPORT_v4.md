## 0. 摘要（基于种子 20240521，最终结论待 3 种子均值）
数据升级 + 增强 + 正则带来**鲁棒性-精度权衡**：
- **改善**：暴风方向误差 30.7°→20.8°、暴风成功率 0.531→0.771；纯风觉从"零放电退化"变为可判别（0.527→0.570，成功率 0.000→0.092）；
  跨模态预激活(priming)恢复（弱风觉 0→0.167、弱叠加 0.017→0.283）；GF 潜伏期普遍快 0.5–0.8ms；高速误报 FAR 0.545→0.510（小幅）。
- **退步（如实）**：干净分布方向误差 10.7°→18.9°、融合成功率 0.903→0.773、触发准确率 0.799→0.762；黑夜召回 0.634→0.624（**未治好**）；
  暴风误报 FAR 0.359→0.590（**变差**）。
- **OOD（2000 条，单列）**：融合 0.592 触发 / 0.520 成功 / 30.0° / 6.09ms；召回 0.970 但 FAR 0.770 —— 分布偏移下高召回高误报。
- **过拟合体检**：无过拟合形态（train−val gap 全程 +0.10~+0.20 为增强使训练分布更难所致，val 一直下降，最优恰在 ep25=0.6861）。

## 1. 方法（v4 相对 v3 的全部差异）
1. 训练样本 5000 → **50000**（威胁 24015，48.0%）。
2. 输入增强（仅训练时）：高斯噪声 σ~U(0, 0.05)（`--noise-std` 可调）+ 模态 dropout p=0.12（整通道置零，缺视觉/缺风觉各 6%）。
3. OOD 测试集 **2000 条**（独立偏移分布，训练/验证从未使用）：速度 60%~U(7,12)+40%~U(3,12) m/s（上限 12 m/s、快威胁占比加大）；
   d~U(3,40)cm；az~U(-2,2)rad、el~U(-0.9,0.9)（角度分布不同）；miss~U(0,10)cm；风压线索 ×2 + 环境风 U(0.01,0.03)cm/ms（风场更强）；
   编码高斯噪声 σ~U(0, 2×0.05)（传感器噪声×2）。标签规则不变（ṙ<0 且 ttc<50ms 且 r<25cm；esc=−r̂）。
4. 3 个训练种子 20240521/20240522/20240523，报 mean±std（**样本标准差 ddof=1**）。
   验证集（1200 条，rng(20240523)，**与 v3 完全同批样本**）与 OOD 集（rng(20240603)）**跨训练种子固定** → std 只反映训练随机性。
5. 正则化：Adam **weight_decay=1e-4**；**早停盯验证损失**（patience=6、最少 8 轮）；检查点按 val_loss 最小选优
   （v3 为每 5 轮 score 选优——差异如实声明）；每轮记 train/val 损失曲线；每轮写 `ckpt_seedXXX.pt` 支持 `--resume` 断点续训。
6. 不变项：EscapeSNN / LIF(β=0.85, Vth=1.0, T=12, dt=1ms, 软复位) / 拓扑 mask / 标签 / 触发判据（GF 首次放电步<12）/ 损失式
   （0.5·BCE+0.5·方向余弦(带 yTrig 掩码)+2e-3·rate·T+0.6·GF放电BCE(pos_weight=2.5)）/ 激活边界 `>0` / BATCH=64 / LR=2e-3+余弦退火。
   方向损失的 yTrig 掩码改动属 v4 阶段 B，本次未动。

## 2. 测速与数据规模（先测速再定）
**结论：维持 5 万训练样本不缩减**（总管批复：数据质量优先于墙钟）。

| 测速项 | 结果 | 备注 |
|---|---|---|
| 训练批次（B=64，前向+反向+step）**短突发** | 0.119 s/批 | `v4\speed_test.json`，外推 5 万 ≈ **94 s/epoch**（乐观） |
| **持续实测（采用配置：独占 12 线程 + OMP PASSIVE）** | **252–520 s/epoch** | 机器被其他任务抢核时劣化到 500–750 s |
| 3 进程并行 8/4/4 线程（OMP 默认自旋等待） | 493–575 s/epoch | 根因见下 |
| 单进程独占 8 线程（自旋等待） | 629 s/epoch | 与"进程竞争"无关 |
| B=1 评估前向 | 6.0 ms/样本 | 全部评估 ≈ 1–2 min/种子 |

**根因**：`v4\batch_probe.py` 逐项对照证明瓶颈是 **OpenMP 默认自旋等待（KMP_BLOCKTIME=200ms）**：
`OMP_WAIT_POLICY=PASSIVE, KMP_BLOCKTIME=0` 后同批计算快 **3–5 倍**。两变量已在 `train_snn_v4.py` 顶部（import torch 前）固化。
**教训**：短突发测速不可外推到持续负载；本机为 12 核/16 线程共享环境，外部任务会造成 2–3 倍波动。

## 7. 与 v3 对比：提升 / 退步（如实）
**提升**：① 暴风方向 30.7°→20.8°、暴风成功率 0.531→0.771（本阶段首要目标之一，达成）；
② 纯风觉模态从"零放电退化"变为可判别（0.527→0.570；成功率 0→0.092；方向 68.0°→46.4°；潜伏期 7.65ms 有定义了）；
③ priming 恢复（弱风觉 0→0.167、弱叠加 0.017→0.283）——模态间协同回来了；
④ GF 潜伏期全面更快（6.57–7.47ms vs 7.53–8.52ms）；⑤ 高速误报 FAR 0.545→0.510（小幅）；
⑥ D 组换体（物理积分口径，单列）：fly 0.698→0.706、drone 0.694→0.696，救回率 0.015→0.025 / 0.010→0.015（小幅，低计数）。
**退步**：① 干净分布方向误差 10.6°→18.9°（融合）/18.2°→20.0°（纯视觉）；② 融合成功率 0.926→0.790、触发 0.801→0.761；
③ 黑夜召回 0.634→0.624、成功率 0.634→0.550（**首要目标未达成**）；④ 暴风误报 FAR 0.359→0.590（变差）；
⑤ 高速召回 0.941→0.891、成功率 0.935→0.799。
**机制解读**：模态 dropout+噪声把网络从"视觉独大"推向"双模态冗余"，换来②③④与鲁棒性，代价是方向精度与干净场景成功率
（鲁棒性-精度权衡）。黑夜未改善的原因：本阶段按任务清单**只做数据量/噪声/dropout/OOD/正则**，未加入环境域随机化
（visGain/ambientWind 增广）——黑夜视觉弱的本质是训练分布里没有"视觉增益 0.3"这种样本，属数据覆盖问题，建议列入阶段 A′ 或 B。
